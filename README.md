# lu-skill
a agents.md archive for ai models
 # **How to install**
 Install the archive in [GITHUB!](https://github.com/whereteto/lu-skill/blob/main/AGENTS.MD) or with `npx skills add whereteto/lu-skill`
  just copy the archive in a repo or only change the skill name to CLAUDE.md for claude or SKILL.md for chatgpt
